# StoryWell 웹소설 창작 스튜디오

장편 웹소설의 설정과 맥락을 보존하면서 전체 회차, 캐릭터, 복선, 소재와 원고를 한곳에서 관리하는 작가용 앱입니다.

## 현재 구현된 1단계 MVP

- 임시 제목·시놉시스·장르·톤·목표 회차 입력
- 12~200화 전체 회차 설계 자동 생성
- 세계관 규칙·주제·핵심 질문·결말 약속 생성
- 주요 캐릭터 바이블과 말투·욕망·비밀 관리
- 회차별 사건·감정 변화·클리프행어 설계
- 복선 설치·발전·회수 보드
- 현재 맥락 기반 소재 우물
- 회차 원고 편집과 저장
- D1 기반 작품 보관함
- 모바일·데스크톱 반응형 화면

## 2단계 AI 창작 엔진

- OpenAI Responses API 구조화 출력 연결
- 12~200화 AI 전체 설계
- 회차별 4,500~5,500자 원고 생성
- 대사·감정선·클리프행어·전체 원고 재작성
- 인물·관계·사건·시간·장소·물건·정보·세계관 기억 추출
- 설정 충돌의 근거와 수정안 제시
- 모든 AI 생성 결과 자동 버전 보관 및 복원
- API 키가 없을 때 안전한 연결 안내

## 다음 개발 단계

1. 캐릭터·복선·회차 상세 편집
2. 회차별 독립 원고와 장면 카드
3. TXT, DOCX, EPUB 및 연재 플랫폼 형식 내보내기
4. 작가 문체 프로필과 금지 표현 사전

## 새 채팅에서 이어갈 때

다음 문장을 새 채팅에 붙여 넣으면 현재 단계에서 계속할 수 있습니다.

> StoryWell 웹소설 창작 앱 개발을 이어서 진행해줘. 현재 2단계 AI 창작 엔진과 스토리 메모리·연속성 검사·버전 복원이 구현되어 있다. 다음 단계는 캐릭터·복선·회차 상세 편집과 회차별 독립 원고, DOCX·EPUB 내보내기다. Sites 프로젝트 storywell-webnovel-studio와 기존 배포 주소를 유지해줘.
