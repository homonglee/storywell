# StoryWell 웹소설 창작 스튜디오

장편 웹소설의 설정과 맥락을 보존하면서 전체 회차, 캐릭터, 복선, 소재와 원고를 한곳에서 관리하는 작가용 앱입니다.

## 현재 구현된 1단계 MVP

- 임시 제목·시놉시스·장르·톤·목표 회차 입력
- 12~200화 전체 회차 설계 자동 생성
- 세계관 규칙·주제·핵심 질문·결말 약속 생성
- 주요 캐릭터 바이블과 말투·욕망·비밀 관리
- 회차별 사건·감정 변화·클리프행어 설계
- 복선 설치·발전·회수 보드
- 현재 맥락 기반 소재 우물
- 회차 원고 편집과 저장
- D1 기반 작품 보관함
- 모바일·데스크톱 반응형 화면

## 다음 개발 단계

1. 생성형 AI 연결: 전체 설계, 회차 원고, 대사 및 장면 재작성
2. 스토리 메모리: 인물 상태·시간선·소지품·정보 범위 자동 추출
3. 연속성 검사: 설정 충돌과 회수되지 않은 복선의 근거 기반 경고
4. 편집 기능: 캐릭터·복선·회차의 상세 편집 및 버전 복원
5. 내보내기: TXT, DOCX, EPUB 및 연재 플랫폼 형식

## 새 채팅에서 이어갈 때

다음 문장을 새 채팅에 붙여 넣으면 현재 단계에서 계속할 수 있습니다.

> StoryWell 웹소설 창작 앱 개발을 이어서 진행해줘. 현재 1단계 MVP가 Sites 프로젝트 storywell-webnovel-studio에 구현되어 있다. 다음 단계는 생성형 AI 연결과 스토리 메모리·연속성 검사 엔진 구현이다. 기존 프로젝트와 배포 주소를 유지하고 수정 후 다시 배포해줘.
